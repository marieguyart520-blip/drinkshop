## 正式使用前確認

1. 前後端都要使用這個同名分支，不能只換其中一邊。
2. 會員表需要組員 008 SQL 所定義的 `geo_source` 欄位。未確認共用資料庫狀態；需要改表時先找資料庫負責人確認，不要自行重跑 SQL。
3. 地圖需要本機私有設定的 HERE_MAP_KEY 與 HERE_API_KEY；範例檔只有設定名稱，不含真實金鑰。實際地圖載入、地址準確度與真實路線仍待設定後人工測試。
4. 組員原有的 GeoCleanupService 會在啟動及每日凌晨 4 點清除 GEOCODE 自動座標，MANUAL 手動座標保留。這是啟動正式後端時會發生的資料異動，本次測試只在 H2 執行。
